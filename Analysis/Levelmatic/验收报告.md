# Levelmatic 中文 AUv3 复刻验收

成品：`Outputs/Release/大鱼音频效果器.app`。源工程：`大鱼音频效果器.xcodeproj`。

## 算法

参考对象为本机 Levelmatic 1.0.8，主二进制身份见 `sha256.txt`。从 ARM64 指令恢复了活跃的 RMS 检测、两遍分段归一化、增益曲线、Hamming 重叠相加、Strength 分段规则与限幅器包装。新代码的最终 `LevelerCore.hpp` SHA-256：

`1eec62215c7b8e28cf532a02fbe241b566659dcf86d6bf926887bee196b0f134`

12 组 Strength/Target 组合，每组 35 秒：420 个逐秒 RMS、420 个逐秒峰值，与原版试用输出均一致到指标报告的五位小数。48 kHz 的声明延迟 362496 帧（7.552 秒），首次非零样本 362497，全部组合一致。

本结果验证已测主要算法路径；不等价于任意输入逐样本 bit-exact 证明。原版是试用状态，没有绕过授权；新实现没有其授权模块和试用水印。详细地址与精度修正在 `leveler-review.md`。

## 界面及功能

参考安装版 nib 的 400 × 405 布局：左侧目标滑杆、中间强度旋钮、右侧输出电平、底部输入/输出波形以及保存/载入/重置/帮助。面板使用参考材质，品牌改为大鱼，菜单和控件中文化。

本实现另提供可折叠高级参数。预设使用自己的 JSON 格式；不将其宣称为原厂私有预设格式。宿主参数保存恢复与 UI 预设保存载入均单独测试。

## 优化

原版可达音频链存在逐样本临时 vector 分配/释放、重复 exp、峰值窗口全扫描、工作线程/锁，以及 Render 缺数据时最长约 3 秒的轮询等待。新实现全部预分配，移除实时锁/等待/线程创建，预计算固定指数，用单调队列维护峰值，并固定内部处理量子。

保留长窗口声音行为也意味着保留约 7.5 秒的宿主补偿延迟。优化消除的是处理和等待成本；没有将另一种短前瞻算法冒充为参考算法。

M1 Max 独立 Metal 试验：64–512 帧双声道 RMS+增益，CPU p50 约 0.29–0.54 µs，Metal 含提交/同步约 235–247 µs。生产实时链路使用 CPU；没有把此简单任务倍率推广成完整算法性能结论。
