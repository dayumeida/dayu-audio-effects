# 用户破音素材：原装ERA5对照与听感不足调查

用户首先反馈移植版“破音修复基本没有效果”，随后实听原装并确认：“我试了，原版就没啥效果”。因此，本次真实素材结论是原版与移植版能力一致、两者在本例的主观改善均有限。忠实移植得到实测验证，但不把本例称为听感修复成功。统一RMS试听只作为候选对照，不能用数值差异代替用户评价。

## 素材与原装对照

素材为 `大鱼多插件长素材验证-011166-1.wav`，5.65秒，48kHz，双声道24bit PCM，271200帧，两个声道完全相同。SHA256：`f49e4e89a9c2845bf81f65e5e76263a9165c85c68775dc0dfeb1bb3acb26ae3e`。原文件保留。无损WAV只能证明当前PCM中的硬饱和，无法可靠判定更早的ADC、模拟前级、AAC等环节分别引入了多少失真；文件也没有此前编码链元数据。不能把“ADC/AAC损坏”当作已证实的诊断。

正常实例化、初始化和渲染未修改的本机ERA5 5.4.00 ARM64 AU（aufx/DcF5/Accu），没有许可证绕过。`ERA5FileProbe.mm`为普通AU宿主，输入通过ExtAudioFile读取，原装延迟5368帧，零输入flush尾部后去除延迟。四模式均与当前生产core的同一素材输出逐样本Float32完全一致：各271200帧×2声道，最大差/RMS差均0。证据 `real-clip-original-vs-new.json`。因此本例不存在仅用合成波形验证而漏掉的DSP迁移差异。主代理还独立验证了真实AUv3宿主渲染输出与standalone core逐样本一致，用于排除FCP包装/参数旁通造成的声学差异。

此外渲染标准两类型的输出−6/−12dB，以及高质量两类型的输出−12dB；查询确认原装参数真实生效。文件位于 `Outputs/破音素材试听/原装ERA5对照/`。

## 检测、修复与回退

当前PCM有7107个满幅点（包括+8388607/8388608与−1），约2.62%。其连续满幅段多数只有1–2点，最长3点；不能把不存在的长平顶当作这段素材的主要特征。原装正常AU经LLDB只读观测得到以下区域数/总长度，均与Analysis中生产头文件的独立仪表副本一致：

|---|---:|---:|---:|---:|---:|---:|
|类型1|1228|11364|4.19%|5143/7107|72.36%|21|
|类型2|2480|27966|10.31%|6163/7107|86.72%|115|

两种品质的检测相同，高质量只改变预测阶数与估计调度。四模式无LPC非有限系数fallback、无几何预测失败、无最终30倍能量回退。标准类型1有22/4906次双向预测的2倍能量保护回退，类型2为42/9910；两声道合计计数，不是相应数量的唯一削波区域。高质量分别0与4次。所有检测覆盖样本最终均有修复变化，故不是“LPC全失败/全退回原始”。但类型1漏过约27.6%的满幅点，类型2仍漏约13.3%，绝大多数发生在最重饱和的第1–3秒。

只读原装证据：`original-internals-q0-t0.json` / `original-internals-q0-t1.json`。独立仪表副本证据：`repair-and-limiter-diagnostics.json`；该副本仅添加计数与导出，不修改生产头。仪表副本输出再次与生产WAV全部逐样本一致。

## 输出余量的实际作用

原装恢复出的、进入限制器前的峰值为类型1标准+8.67dBFS/高质量+8.90dBFS，类型2标准+11.14dBFS/高质量+11.25dBFS。默认输出增益0dB时必然要由限制器压回，标准类型1最深约−8.67dB、类型2约−11.14dB。该素材默认标准类型1RMS由输入−7.89变为输出−11.15dBFS；其中修复矩阵本身RMS为−8.14，限制器带来约3dB额外平均能量降低。

输出增益改为−12dB位于限制器之前。本例四模式的全部重建峰值均能留在0dBFS以下，原装−12dB输出与“修复矩阵×固定缩放”最佳拟合残差RMS仅约3.5e−9、最大约7e−8，证明它保留了重建波形，而非只把默认已限幅的结果整体变小。证据 `headroom-preservation.json`。

为消除音量比较误导，所有试听候选及原始素材共同匹配到 **−21dBFS RMS**，所有文件峰值≤−1dBFS。统一目标由各候选最大峰均比计算，未给不同文件不同目标，没有为满足峰值单独压缩任何一份。标准类型1默认0dB与−12dB在同响度后仍有非零波形差异：差值RMS−36.19dBFS，相关0.98486。证据 `level-matched-comparisons.json`。这证明音色/动态变化存在，不证明主观修复一定更好。

## 试听顺序与当前可操作设置

建议先比较以下四份（全部同一−21dBFS RMS）：

1. `01_原始素材_同响度-21dBFS-RMS.wav`
2. `02_标准类型1_输出0dB_同响度-21dBFS-RMS.wav`
3. `04_标准类型1_输出-12dB_同响度-21dBFS-RMS.wav`
4. `07_高质量类型2_输出-12dB_同响度-21dBFS-RMS.wav`

路径均在 `Outputs/破音素材试听/同响度对照/`。类型2扩大了本例检测覆盖，高质量较少触发能量保护，输出−12dB保留了所有重建峰，所以“高质量＋类型2＋输出−12dB”为最值得实听比较的候选；若作为工程设置希望峰值≤−1dBFS，可用−13dB输出。高质量适合预渲染；不要在后级把12dB全部直接加回并重新削顶。

这段素材没有未削波的真实干净参考，无法客观证明LPC外推的峰值就是原始波形，更不能承诺消除已有的全部非线性或编码失真。用户现已确认原装在本例也改善有限，本轮保留这一能力边界并结束本项调查，不扩展其他算法、不修改默认声学行为，也不追加试听候选。将来若另行请求增强，应单独定义增强目标与验收，不能把另一种修复算法称为原装移植。
